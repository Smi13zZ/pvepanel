## 4. 数据消失（最严重的一个）

### 现象

PVE 9 那台的数据会突然清空，过一会又回来。

### 根因

两层问题叠在一起：

**服务端**：采集一开始会打一个**免认证的指纹探测**（只为拿版本号和节点名）。这个请求一旦超时，代码直接 `return` 掉整轮采集 —— 一个装饰性信息的失败，把整轮真实数据全丢了。

**前端**：`applySnapshot()` 无条件用新快照替换旧的。所以只要有一次轮询返回 `ok:false`，页面瞬间变空；下一次轮询成功，数据又回来。

### 实测复现

```text
40 次连续轮询（非强制，走 TTL 缓存路径）：
  FAIL#1: False unreachable 0        <- 第 1 次就命中，返回空快照
  failures: 1 / 40
15 次强制轮询：failures: 0 / 15      <- 强制刷新反而没事，所以平时很难撞到
```

### 修法

1. 指纹探测失败**重试一次**，还失败就记个警告继续跑 —— 认证端点才是真正的可达性判据
2. 集群状态失败时**沿用上一次的节点列表**，而不是假装集群是空的
3. 如果所有节点查询都失败（全新采集），才判定为真的不可达，返回上一份好数据（标记 stale）
4. 前端：失败的响应**不覆盖**已有数据，只把错误挂到状态栏

### 验证

```text
修复后 40 次轮询：failures=0  empty_guest_lists=0
冷启动 bootstrap：rrd 60 点 / guests 4 台
```

## 2. 资源曲线首次不显示

### 根因

canvas 只在 `refresh()` 完成、窗口 resize、手动切页面时才画。**首屏走的是 `bootstrap()`，它把数据填好了，但没有任何东西去碰 canvas**。所以必须点一下时间档位（触发 `refresh`）图才出来。

### 修法

- `bootstrap` 完成后主动画一次
- `go()` 切页时也画（视图是用 v-if 重建的，canvas 元素每次换新，缓存的图表实例要重新绑定）
- 快照更新后也画

现在首屏、切页、切服务器、切时间档位，四种情况都会重绘。

## 3. 设置页按钮

| 问题 | 原因 | 修法 |

| 按钮贴顶不居中 | 按钮是 `.alert` 的直接子元素，而块是 `align-items: flex-start` | 包一层 `.row-acts`，`align-self: center` |

通知通道那几行是同样的结构，一起改了。

## 1. 官方图标

### 拿的是哪个

PVE 官方 Web UI 自带的 `/usr/share/pve-manager/images/logo-128.png`（从测试机的 PVE 9 里直接取的），就是那个**四臂渐窄的橙色 X**。原图存在 `reference/pve-logo-128.png`，构建可复现。

### 怎么做到「高清」

原图只有 128×128，直接放大到 512 会糊。所以不是放大，而是**重新栅格化**：

1. BICUBIC 放大到 1024
2. **对 alpha 通道做 50% 阈值** —— 这个标记是两色平涂，阈值能把边缘收敛回原始几何，不是凭空猜的
3. 再 LANCZOS 降到每个目标尺寸，得到干净的反锯齿

这样 512 档是锐的，同时形状**和官方原图逐像素一致**。

（中间我试过两次手绘几何：一次把臂画成了整条交叉线，一次画成方头。都因为「臂是外宽内窄的楔形」这个细节出错，最后决定不再猜，直接用官方原图。）
