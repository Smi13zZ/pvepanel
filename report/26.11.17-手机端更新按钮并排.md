# 26.11.17 手机端更新页按钮并排

## 问题

手机端「设置 → 更新」的状态条里，「检查更新」与「一键更新」各占一行，纵向多出一大截。

## 修法

给两个按钮包一层 `.vactions`：

```css
/* 桌面端：这一层不参与布局，按钮直接作为 .vstatus 的 flex 项排在文字右边 */
.vactions { display: contents; }

/* 手机端：这一层独占一行，内部两个按钮左右均分 */
@media (max-width: 640px) {
  .vstatus .vactions { display: flex; order: 3; flex: 0 0 100%; gap: 8px; }
  .vstatus .vactions .btn { flex: 1 1 0; min-width: 0; }
}
```

`display: contents` 是关键：桌面端这一层不生成盒子，两个按钮仍旧是 `.vstatus` 的直接
flex 项，位置与加这层之前一致。

同时把图标与两行说明文字放回同一行（`flex: 1 1 0` + `min-width: 0`），文字吃掉剩余
宽度，不再被挤成窄列频繁折行。
