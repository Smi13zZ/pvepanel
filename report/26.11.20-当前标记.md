# 26.11.20「当前」标记

## 需求
设置-服务器里标出当前选中的那一台、设置-存储里标出当前正在运行的那一个安装包。
服务器卡原本已经是对的实心反转色，存储表那处却是浅灰底绿字的小胶囊，两处不一致；
本次并到同一个类，并统一成参照的实心反转色药丸：浅色主题近黑底白字、深色主题近白底深字。

## 改动
| 文件 | 位置 | 改动 |
| --- | --- | --- |
| `app/web/index.html` | 服务器卡「当前」 | `class="tag tag-cur"` → `class="tagcur"` |
| `app/web/index.html` | 存储表「当前版本」 | `class="chip ok"` → `class="tagcur"` |
| `app/web/style.css` | `.tag` / `.tag-warn` 之间 | 删 `.tag.tag-cur`，新增 `.tagcur` |
| `app/web/style.css` | 存储表样式段 | 删 `.ttable.tstorage .chip.ok`（改类名后已无匹配元素） |
| `app/web/index.html` | `<link>` 的 `?v=` | 26.11.4 → 26.11.20 |
| `manifest` | `version` | 26.11.19 → 26.11.20 |

`.tagcur` 用 11px 字 / 3px 6px 内边距 / 5px 圆角，取 `--primary` + `--primary-fg`，
主题切换时颜色随之翻转，不需要额外逻辑。

保留：`.chip` 基础类、`.chip.err`（「半截」标记还在用）、
`.ttable.tstorage .chip` 的 20px 高 / 11px 字（同为「半截」服务）。
